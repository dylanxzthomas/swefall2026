# Daymark for iPhone

The existing Capacitor app now bundles Daymark. The bundle identifier remains `com.dylanxzthomas.wren`, and the earlier Preferences keys are preserved. The default app opens a no-account device workspace. Authenticated Convex shared state is optional and separate; local work and earlier organizer records are not silently uploaded.

## Native implementation

- System-browser Auth0 authorization with PKCE and a native callback; tokens use a custom Keychain-backed Auth0 cache. The exact Auth0 PKCE transaction is also saved in Keychain before opening the browser, restored before SDK startup after termination, and cleared after the callback or 15-minute expiry. Google and Microsoft consent return through separate callbacks.
- Apple Calendar uses full-access EventKit permission and lists writable calendars already on the phone, including configured iCloud accounts. Explicitly approved saves/changes/removals produce a local read-back receipt, never a claim about cloud sync. A protected operation journal prevents replay after an ambiguous write. Connected work is bound to the original app installation and waits for that iPhone to open; calendar and Outlook/Gmail sending accounts remain separate.
- A Share extension accepts text, URLs as text, images and PDFs. It saves an atomic manifest and files in an App Group. The extension says **“Saved on this phone—open Daymark to upload.”** It never claims server receipt.
- Opening Daymark offers the pending notice in the composer. Files/text are persisted in the local outbox before acknowledging the App Group handoff. Cloud upload requires sign-in and household confirmation; device-mode preparation stays local. Shared URLs are not automatically fetched.
- Image conversion occurs locally in the extension; it rejects images over 12 megapixels to bound extension memory. Server intake separately validates file type, total size, and PDF page/encryption limits.
- Optional APNs registration, generic notifications without child details, job deep links, foreground suppression, and server-side quiet hours. The AppDelegate forwards registration results to Capacitor.
- Floating Assistant/Plan navigation, grouped household settings, a bottom composer, editable sheets, and automatic light/dark appearance. Controls remain labeled for accessibility. Native background colors follow appearance; composer keyboard/header recovery is verified at the tested default size. Broader safe-area and accessibility checks remain below.
